# Simple Books Catalogue

## Task
Implement a small web application (without using any libraries or frameworks) that allows you to search for books by title via a public API, view the results, and add your favorite books to your "favorites" while saving the data.

## How to run the app

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Build a production bundle:
   npm run build
4. Preview the built app locally:
   npm run preview

### Folder structure

- `src/`: application source files (`main.js`, styles, logic)
- `assets/`: static imagery and icons used by the interface
- `index.html`: main entry point for the app
